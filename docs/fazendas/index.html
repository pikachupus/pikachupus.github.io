Como conferimos. Os anúncios vêm da OpenSea (coleção Sunflower Land, rede Polygon). Os dados de cada fazenda vêm do próprio jogo: o arquivo diário oficial com todas as fazendas e, ao longo do dia, uma reconsulta na API do jogo, que confirma de novo o banimento das anunciadas (a data aparece em "conferida em").
Limpa = sem banimento. Em análise = o jogo está investigando (pode virar ban). Banida = bloqueada; comprar uma dessas é perder o dinheiro. Último save = última vez que a fazenda salvou o jogo. Skills legacy = insígnias antigas que não se ganham mais. Valor dos itens = quantidade × preço atual no market do jogo (colecionáveis, recursos e vestíveis). Vendedor em lote = carteira anunciando 5 fazendas ou mais. Confira sempre o anúncio na OpenSea antes de comprar: aqui é só uma ajuda.
