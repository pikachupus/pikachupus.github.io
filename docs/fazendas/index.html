Banimento conferido direto no jogo. Nenhuma fazenda banida, em análise ou bloqueada aparece como "limpa". A situação de cada anunciada é reconferida na API oficial do jogo ao longo do dia (—), além do arquivo diário oficial. Mesmo assim, confira na hora da compra: o ban pode acontecer depois.
Como conferimos. Os anúncios vêm da OpenSea (coleção Sunflower Land, rede Polygon). Os dados de cada fazenda vêm do próprio jogo: o arquivo diário oficial com todas as fazendas e, ao longo do dia, uma reconsulta na API do jogo, que confirma de novo o banimento das anunciadas (a data aparece em "conferida em").
Limpa = sem banimento. Em análise = o jogo está investigando (pode virar ban). Banida = bloqueada; comprar uma dessas é perder o dinheiro. Último save = última vez que a fazenda salvou o jogo. Skills legacy = insígnias antigas que não se ganham mais. Valor vendável = NFTs (colecionáveis) e vestíveis que estão dentro da fazenda × preço médio pelo qual estão sendo vendidos agora no market do jogo; é o que daria para tirar vendendo esses itens (recursos e skills ficam de fora; skill legacy não tem preço). Vendável ÷ preço = quantas vezes o que tem dentro vale o preço da fazenda. Vendedor em lote = carteira anunciando 5 fazendas ou mais. Redes sociais: o jogo informa Discord (conectado/verificado) e Telegram; Twitter e verificação facial não vêm nos dados públicos, então não aparecem aqui. Confira sempre o anúncio na OpenSea antes de comprar: aqui é só uma ajuda.
